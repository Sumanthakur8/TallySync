Privacy first

Your accounting file stays in your browser.

This tool uses SheetJS in the browser to read and process your CSV/Excel file. No GST report is sent to a TallySync server by this page.

Supplier names: The tool first uses a party/trade/legal name present in the GST report, then your Supplier Master. If neither contains a name, the GSTIN is shown without guessing. An API can be connected later through a secure server-side endpoint without exposing API keys in the browser.
