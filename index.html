QUICK ANSWERS04 QUESTIONS
01What kind of PDF should I upload?

Use a bank-generated digital PDF downloaded from internet banking, a banking app, or email. Scanned image-only statements need OCR and are not handled by this browser-only demo.

02Can it handle password-protected PDFs?

Yes. If the PDF requires a password, the converter asks for it and passes it to the PDF reader. The password is not stored.

03What if my bank's columns look different?

The converter uses generic transaction detection. Different bank statement layouts may need adjustments, so always review the extracted entries before using the output.

04Does this upload my financial data?

This implementation performs PDF extraction in your browser and does not send the selected PDF to a server. External libraries are loaded from public CDNs.
