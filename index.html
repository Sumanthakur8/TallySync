FAQ

Questions, answered.

What kind of PDF should I upload?

Use a bank-generated digital PDF downloaded from internet banking, a banking app, or email. Scanned image-only statements need OCR and are not handled by this browser-only demo.

Can it handle password-protected PDFs?

Yes. If the PDF requires a password, the converter asks for it and passes it to the PDF reader. The password is not stored.

What if my bank's columns look different?

The converter uses generic transaction detection. For production use, add a bank-specific parser for each statement format you need to support.

Does this upload my financial data?

This implementation performs PDF extraction in the browser and does not send the selected PDF to a server. The external libraries are loaded from public CDNs.
