Tally workflow

How the bank-to-Tally process works

The converter is designed to reduce manual entry while keeping the accounting workflow visible and controllable.

1
Upload PDF

Select a bank-generated digital statement.

2
Read & detect

Extract transaction dates, descriptions, debit, credit and balance information.

3
Review

Check the transaction preview before exporting.

4
Choose ledgers

Select the Tally bank ledger that should receive the records and the reference ledger.

5
Export

Create CSV, Excel or Tally XML files for the next step in your workflow.

Tally voucher logic

The Tally export is designed around the bank ledger you choose as the account being recorded. The reference ledger can be set to Suspense for the offset side.

Payment / WithdrawalSuspense is debited and the selected bank ledger is credited.
Receipt / DepositThe selected bank ledger is debited and Suspense is credited.
Reference ledger: A separate master XML can be generated for the reference ledger so it can be created in Tally if it does not already exist. The exact import result should always be checked against the Tally company configuration.
